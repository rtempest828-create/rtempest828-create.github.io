League of Legends companion for Windows

Yoru

Profile overview, team-aware builds and a small in-game item overlay. A personal, non-commercial project that runs locally on my own PC.

  • Desktop app (Electron)
  • Interface in German
  • Not publicly distributed
  • No ads, no payments

What Yoru does

Profile
Ranked tier and LP, LP history, champion mastery, recent matches with KDA, CS and items, champion statistics and the players I queue with most. Works for my own Riot ID and for any Riot ID I type in.
Champion select builds
When I pick a champion, Yoru suggests runes, summoner spells and items adjusted to the enemy champions that are visible in champion select: healing, shields, tanks, AP/AD split and crowd control. On lock-in it can save the rune page and an item set to my own client.
In-game overlay
A small window that shows the next recommended item and how much gold is still missing. It uses only the scoreboard-level data of the official Live Client Data API and can be hidden with a hotkey.
Build statistics optional, off by default
Reads ranked Solo/Duo matches of Master+ players in my region and keeps only aggregated numbers per champion, role and patch: win rates of items, rune pages and lane matchups. It pauses while I am in a game.

How Yoru uses the Riot API

Every request is made from my own PC with my own key. There is no Yoru server and no shared backend.

APIEndpointUsed for
ACCOUNT-V1/riot/account/v1/accounts/by-riot-id/{gameName}/{tagLine}Turning a Riot ID into a PUUID when I open a profile
SUMMONER-V4/lol/summoner/v4/summoners/by-puuid/{puuid}Summoner level and profile icon
LEAGUE-V4/lol/league/v4/entries/by-puuid/{puuid}Tier, division, LP, wins and losses
MATCH-V5/lol/match/v5/matches/by-puuid/{puuid}/ids
/lol/match/v5/matches/{matchId}		Match history, 20 matches per page
CHAMPION-MASTERY-V4/lol/champion-mastery/v4/champion-masteries/by-puuid/{puuid}/topTop 5 champion masteries on the profile
LEAGUE-V4/lol/league/v4/{challenger|grandmaster|master}leagues/by-queue/RANKED_SOLO_5x5Player list for the build statistics optional
MATCH-V5/lol/match/v5/matches/{matchId}/timelineStarting items, item and skill order for the build statistics optional
  • Rate limits: a client-side limiter reads the key's limits from the X-App-Rate-Limit response header (currently 20 requests per second, 100 per 2 minutes). Requests I trigger myself go before statistics requests, and Retry-After on 429 responses is respected.
  • Caching: match details are cached on disk because finished matches never change. Account, rank and league lists are cached in memory for minutes to hours.
  • Key storage: the key lives only in a local settings file on my PC. It is never part of the source code or of a build.

Other data sources

  • League Client (LCU): read through the client's lockfile on the same PC, so no login or password is involved. Used for the current summoner, ranked stats, champion select and saving rune pages and item sets.
  • Live Client Data API (127.0.0.1:2999): polled every 2 seconds, only while a match is running.
  • Data Dragon: static champion, item, rune and summoner spell data, cached per patch.

Fair play

Yoru only shows information a player can already see in the client or on the in-game scoreboard. These features are left out on purpose and will not be added:

No timersNo enemy ultimate, summoner spell, jungle camp or objective timers.
No de-anonymizingNo revealing of names in champion select and no lobby lookups.
No game modificationNo memory reading, code injection or input automation.
No adsNothing in the overlay, the client or the app.

Data and privacy

  • All data stays on my PC: settings, LP snapshots and the aggregated build statistics.
  • The build statistics contain no player names or PUUIDs, only counts per champion, role and patch.
  • Only the current and the previous patch are kept. Older statistics are deleted automatically.
